# 朱雀 AI 检测（检测模块）

本文件是 `gzh-creation-system` 的 AI 率检测模块说明。脚本在本 skill 的 `scripts/zhuque.py`，只用 Python 标准库。

这一步只测**降AI后稿**（润墨返回的那份，排版之前）的 AI 率，把结果报给用户。降AI前稿、发布稿不送检：实测 human-writing 重写稿直接送检会判到 100% 疑似 AI，测它没有意义；排版不改文字，发布稿不必重测。**检测本身不改稿**；超阈值时停下来让用户决定怎么办。

## 一、何时执行

**条件步骤**，润墨产出降AI后稿之后、排版之前执行。满足两个条件才跑：

- 本 skill 的 `scripts/zhuque.py` 存在且能调用
- 密钥可用（命令行 `-k`、环境变量 `ZHUQUE_API_KEY`、工作区 `工具/zhuque.key`，按这个顺序读取）

任一不满足就一句话说明并跳过，直接交付，**不中断流程**。

## 二、密钥

密钥由腾讯 EdgeOne 控制台（Makers → 模型 → API Key）生成。密钥是明文，**不写进本文件、SKILL.md、脚本或任何分享包**；命令、日志、回复里都不出现。外泄了就去控制台撤销重发，替换 `工具/zhuque.key` 的内容即可。

## 三、调用命令

```bash
python "{技能安装目录}/scripts/zhuque.py" "<成品目录>/<文章名>-降AI后.md"
```

- 脚本先去掉 frontmatter、`#`、`**`、图片与链接标记，只把读者看到的文字送检
- `-t 50` 阈值（百分比），默认 50；用户改了口径就改这里
- 退出码：`0` 通过，`3` 超阈值，`1` 调用失败或缺密钥

输出示例：

```
字数：574
AI率：0.0%（AI 0.0% / 疑似AI 0.0% / 人工 100.0%）
整体风险分：0.1660
判定：通过（阈值 50%）
扣减额度：957 token
```

超阈值时还会逐条列出被判为 AI / 疑似AI 的片段开头。

## 四、结果处理

- **通过**：把 AI 率写进素材存档 frontmatter 的 `AI率` 字段，进入交付。超阈值的情况，用户选完后同样写入最终采用的那次 AI 率，照常交付的注明「超阈值，用户确认交付」。
- **超阈值**：用 `mcp__ask-user__ask_user` 卡片停下问用户，带上 AI 率和被标出的片段，选项固定为：
  1. 照常交付（接受当前结果）
  2. 换另一个模式重跑润墨（重新排版后再测一次）。跑的是 `deep3` 就换 `deep`（2.0），兜底已用 `deep` 就换 `deep3`；同模式重跑意义不大。这篇没跑成润墨（缺密钥或失败）时去掉这一项
  3. 我自己改，先交付现有文件
- 用户选重跑时，新文件用版本号保护，不覆盖原降AI后稿与发布稿。**同一篇最多重跑一次**，再超阈值就照常交付并如实报告，不进入循环。
- **不根据检测结果自行改写正文**。排版红线不变，润墨返回的正文依然不改。
- **调用失败**：报错原因，跳过这一步直接交付，在未解决项里写明「未完成 AI 率检测」。

## 五、接口本身（脚本已封装，备查）

| 项 | 值 |
|---|---|
| 地址 | `POST https://ai-gateway.edgeone.link/v1/providers/zhuque-text/classify` |
| 认证 | `Authorization: Bearer <API_KEY>` |
| 请求体 | `{"text": "...", "is_merge": true}`（`is_merge` 可选，默认合并段落） |
| 返回方式 | 同步，直接返回结果 |
| 额度 | Makers 每月免费 50 万 token；一篇约 600 字的发布稿实测扣约 1000 token |
| 文档 | https://cloud.tencent.com/document/product/1552/137539 |

返回字段：

| 字段 | 含义 |
|---|---|
| `status` | `success` 表示完成 |
| `labels_ratio` | 内容占比，`"0"` 人工、`"1"` AI、`"2"` 疑似AI；脚本的 AI 率 = `1` + `2` |
| `softmax_confidence` | 整体风险分，越高越像 AI |
| `ratio_confidence` | 疑似风险内容占比 |
| `segment_labels` | 分段结果，含 `text`、`label`、`conf`、`position` |
| `makers_models_usage.total_tokens` | 本次实际扣减的免费额度 |
| `msg` | 错误信息，成功时为空 |
